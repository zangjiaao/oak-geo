## 本次调整与未变更的规则

产品方向由负责人本轮明确调整为方法论验证优先，取代旧版先建行业管道、完整后台、分析Agent后置的执行顺序。历史附件的旧指令仅解释当时任务，不覆盖本轮授权。AGENTS.md不修改；与旧分期冲突时记录并遵循本轮用户明确授权，其余约束继续执行。

研究输出可先用受控文档，必须记录来源、时间、假设、Agent版本、人工纠正、未知项和实际成本。涉及敏感原文仍按服务授权单条访问与审计，不批量导出给Agent。资料不足、需求不适用、建议不执行、零／负增长都是可记录的结果。

正式采样、judge、评分和机会卡准入仍受已批准契约约束。本次不改变模型清单、温度、轮次、数量、状态机、权限或判据，不自行冻结新规格；研究笔记不能冒充正式基线／机会卡。若实验发现约束妨碍方法验证，另提具体变更及影响供人审，而非捏造数据绕过校验。

现有文档与单元检查通过只证明记录一致；真实联调、分析质量和发布后复测结果分别验收。通用Runtime、MCP Server、完整后台和自动分发继续后置。
